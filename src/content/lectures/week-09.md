No voice chat, no shared instance, no real-time signal — and the online
layer still produces a stranger's presence, out of a message you can say in
about ten words. The full argument for how a templated message system, a
bloodstain and a phantom replay do that work is in
[Asynchronous resonance](/topics/asynchronous-resonance/).

## The argument

Death Stranding pushes the same restriction further than any Souls-like
does, by removing language from it entirely: a ladder or a rope another
player left across a ravine can only be acknowledged with a wordless
"like," and that single silent gesture still produces something close to
gratitude — arguably a purer version of this course's argument, since
there's no phrase left to misread, only an object someone else chose to
leave and a thumbs-up with no tone at all. Journey runs the opposite
experiment: two strangers matched in real time, present in the same
instant, but restricted to a single musical chime as their entire
vocabulary. Contact without language works there for the same reason
templated messages work here — restriction, not richness, is what makes a
stranger's gesture legible without being verifiable.

Dark Souls' own message system sits between those two poles: a small,
fixed vocabulary of phrases and blanks ("Try", "jump", "ahead") that can
express either genuine help or outright deception using identical words.
"Try jumping" placed before a hidden item and the same words placed before
a fatal drop are indistinguishable until you commit to the jump — which is
this course's core test, applied to a total stranger. Elden Ring expands
the phrase set considerably and adds gestures, trading some of that
severity for expressiveness; the fact that it still refuses free text shows
the restriction, not the vocabulary size, is the load-bearing part of the
design.

## Outline

- why a restricted, templated vocabulary produces more trustworthy-feeling
  messages than free text would
- Death Stranding's wordless "like" as the same principle with language
  removed entirely
- Journey's single-chime vocabulary as the same principle applied to two
  players actually present together
- the message as simultaneously legible (a specific claim) and arbitrary
  (unverifiable) — the genre's core test, applied to strangers
- Elden Ring's larger phrase set and gestures: more expressive, still not
  free text
- the bloodstain and the phantom as replay rather than presence
- this week's workshop: writing deceptive and helpful message templates for
  five dangerous locations

## Into the session

Pick five moments from any game — a hidden item, a fatal drop, an ambush, a
secret wall, a fake-safe room — that a stranger passing through wouldn't
yet know about. In the session you'll design a fixed vocabulary of your
own and write, for each location, one message that would genuinely help a
stranger and one that would deceive them, using the same words wherever
possible. If a partner can tell which is which from the message alone, the
vocabulary is carrying more certainty than the system should allow.
