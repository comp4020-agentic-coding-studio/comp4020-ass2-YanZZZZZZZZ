No quest log, no marker, no journal. Delete the quest log and you haven't
simplified the interface, you've made the world responsible for
everything it used to do. The full argument for why that subtraction is
design rather than neglect — and what it bets the player will retain
instead — is in [Minimal UI and immersion](/topics/minimal-ui/).

## The argument

The subtraction is selective, not absolute, and the exception proves the
rule. Elden Ring reintroduces a map screen with player-placeable markers —
on paper, a concession to exactly the convenience this course's earlier
entries refuse — but it still withholds the quest log and the objective
marker completely. The difference is what each element would do to
interpretation: a map still requires the player to read terrain and decide
a route, so it can return without breaking the bet; a quest log would
simply state the answer, which is the one kind of help the genre never
gives back regardless of how the rest of the UI evolves.

Set that against a typical open-world HUD — minimap, quest tracker,
objective marker, compass, all visible simultaneously — and the contrast
names exactly what's being subtracted. A player of that HUD never has to
remember which door a key unlocked, never has to notice that a merchant
mentioned a shortcut in passing, because the interface is doing that
remembering for them, continuously, whether or not the moment mattered.
Delete all four elements and none of that information vanishes from the
game — it just moves from the corner of the screen into the player's own
memory, which is exactly the trade [level
design](/topics/level-design-and-geography/) already makes for navigation,
applied here to everything else a HUD used to hold.

## Outline

- the quest log as a promise the genre deliberately withdraws
- Elden Ring's map-with-markers as a selective exception: geography can
  return because it still requires interpretation, a quest log couldn't
- the typical open-world HUD (minimap, tracker, marker, compass) as the
  maximal case being subtracted from
- subtraction applied to memory, the same move level design applies to
  navigation
- the real cost of the bet: players do forget, and the genre accepts that
- why a redesign that just repositions elements hasn't engaged this week's
  argument, only decorated it
- this week's workshop: redesigning a cluttered HUD by removing rather than
  adding

## Into the session

Bring (or use one supplied in the session) a screenshot of a busy HUD —
quest tracker, minimap, objective markers, buff icons, all of it. In the
session you'll redesign it by deletion only: no repositioning, no new
elements. For every element you cut, name one sentence what the player now
has to remember or notice in the world instead of on the screen — if you
can't name a replacement, the element wasn't scaffolding memory, and
cutting it may just be a loss.
